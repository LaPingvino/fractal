# Fractal with spaces

This is a build of [Fractal](https://gitlab.gnome.org/World/fractal), the GNOME Matrix client, with
extra support for Matrix spaces: spaces in the sidebar, a space page, and work on how both read with a
screen reader.

It installs next to the regular Fractal as "Fractal (Development)", so both can be used.

## Install

You need Flatpak with Flathub. Most distributions have it; if not, see https://flathub.org/setup.

1. Download `fractal-spaces.flatpak` from the release page:
   https://github.com/LaPingvino/fractal/releases/tag/spaces-latest
2. In a terminal, in the folder where you saved it, run:

       flatpak install --user fractal-spaces.flatpak

   Flatpak asks to also install the GNOME runtime from Flathub; answer yes.
3. Start it from your applications menu as "Fractal (Development)", or with:

       flatpak run org.gnome.Fractal.Devel

### On Arch Linux, as a native package

Download `fractal-spaces-x86_64.pkg.tar.zst` from the same release page and run:

    sudo pacman -U fractal-spaces-x86_64.pkg.tar.zst

It replaces the regular `fractal` package (both use the same program name). To build it yourself:
`packaging/arch/PKGBUILD` on this branch, with `makepkg -si`.

## Update

Download the file again and run the same install command. A new build is made every night and whenever
the work changes.

## Remove

    flatpak uninstall --user org.gnome.Fractal.Devel

## Why this is not in Fractal itself

Fractal's contribution guide has a clear rule:

> Contributions must not include content generated by large language models or other probabilistic tools
> like ChatGPT, Claude, and Copilot.

Their reasons, in their own words: ethical concerns about how the training data was gathered, the
electricity and water these models use, the effect of generated content on quality, and possible copyright
problems. The rule covers code, documentation, issues and artwork alike.

The spaces work in this repository was written with the help of an AI assistant (Claude), so under that rule
it cannot be offered to Fractal, and it isn't. We respect that: no merge request, and no issue written by a
model.

It exists anyway because of who it is for. A blind friend of the author uses Matrix through a screen
reader, and spaces were hard to get around in Fractal for him; with his friend's help this was one of the
very few ways to get something that works for him now, rather than at some unknown point in the future.

So the work is kept as a separate, openly labelled branch:

- the commits keep their `Co-Authored-By: Claude` lines — nothing is disguised;
- it is kept small and in Fractal's own style, and rebased onto Fractal's main every night, so that if the
  project ever changes its position it is ready to be offered as it is, together with an explanation from the
  person it was made for;
- until then it is only built and shared here.

The author's own view, for what it's worth: AI-assisted work has improved a great deal, and he hopes the
reasons behind such rules will be looked at again as that continues. That is a conversation for Fractal's
maintainers to have on their own terms; this branch does not try to force it.

The source is on the `spaces` branch of this repository.
